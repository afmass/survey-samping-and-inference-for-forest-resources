# survey-sampling-and-inference-for-forest-resources

These materials support the FIRS UE1-UC1 course on Survey Sampling and Inference for Forest Resources. Topics include the Monte Carlo interpretation for continuous population sampling in forest inventories, model-assisted estimation and small area estimation.

## Getting started

You do **not** need a GitHub account or any knowledge of Git to use these materials.

To download the course materials:

1. Download the repository as a ZIP file from GitHub by clicking **Code → Download ZIP**.
2. Decompress/unzip the downloaded file on your computer.
3. Open the resulting folder.
4. Double-click the `.Rproj` file to open the course project in **RStudio**.

Opening the `.Rproj` file is important because it sets the course folder as the RStudio project directory, allowing the exercises to find the datasets using the correct file paths.

## Exercises

The exercises are provided as `.html` documents in the `exercises` folder.

Open the HTML files in your web browser to read the exercises and view the code. The datasets required for the exercises are included in the `data` folder.

To work through the R code, use the RStudio project you opened from the `.Rproj` file.

## Lecture slides

The lecture slides are provided as HTML documents in the `slides` folder.

Open the `.html` files in your web browser to view the slides.
